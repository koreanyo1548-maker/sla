# v0924_1 · 완성도 개선

2026-09-24. CrazyGames 심사에서 받은 완성도 피드백에 대응하는 화면·연출·첫 플레이 수정이다. 심사 통과나 실행 검증 완료를 의미하지 않는다.

## 플레이어에게 달라지는 것

- 대장간 로비부터 전투·수호자·스킬·강화·결과까지 어두운 청회색 패널, 금색 강조, 청록색 에너지 표현으로 맞췄다. 로비에 게임명과 한 줄 소개를 넣고 미완성 유물 메뉴를 숨겼다.
- 전장 배경을 새 이미지로 교체했다. 중앙은 어둡고 넓게, 용암과 장식은 가장자리에 배치한다. 가장자리 불씨와 핵의 바닥 문양을 표시하며 움직임 줄이기 설정을 따른다.
- 기존 수호자 초상화·전투 스프라이트는 보존했다. 로비 초상화의 정사각 아틀라스 비율을 유지하면서 카드 안에서 잘라 표시한다. 전투에서는 호흡·발사 반동, 간결한 레벨 표식, 빈 소환 자리의 속성 문양을 더했다.
- 스킬 11종에 일관된 SVG 아이콘을 사용한다. 장착 슬롯·목록·상세·성장·전투가 같은 그림을 공유한다. 보석은 등급별 받침과 작은 등급 표식으로 구분한다.
- 주문서에는 미사일 아이콘, 사용 재료, 소환/강화 동작과 실제 강화표의 증가량을 표시한다. 설명 버튼은 정보 아이콘으로 바꿨다. 완료 연출 중 재렌더돼도 중복 제출되지 않게 슬롯에 처리 상태를 둔다.
- 적의 보행과 공격 직전 예고, 불꽃·산탄의 서로 다른 탄 모양, 성장에 따른 작은 탄 크기 증가를 표시한다. 일반 적 체력바는 피해를 입은 뒤 표시하고 보스 체력바는 유지한다. 이 변화는 표시 전용이다.
- 별도 음원 다운로드 없이 Web Audio로 효과음과 두 장면의 배경음악을 만든다. 생성·머지·미사일 종류·주문서·스킬·보스·성장·승패가 서로 다른 소리를 낸다. 동시 발음 수와 연속 타격음 간격을 제한하고 효과음/음악을 따로 끄거나 음량을 조절할 수 있다. 첫 사용자 입력 뒤에만 재생하며 설정을 저장한다.
- 최초 1스테이지는 생성 2회 → 직접 머지 → 첫 주문서 → 스킬 순서로 진행한다. 안내에 필요한 두 보석은 같은 색으로 생성하며 앞의 세 단계 동안 전투 시간을 멈춘다. 스킬 안내에서는 전투가 절반 속도로 진행되고 사용 또는 건너뛰기 뒤 정상 속도로 돌아온다. 기존 튜토리얼 완료 저장값을 재사용한다.
- 일시정지 버튼과 P 단축키, 1/2 스킬 단축키를 추가했다. 설정창·주문서 상세·백그라운드·모바일 가로 회전 안내 중에는 전투 시간을 멈춘다. 다른 탭이나 회전에서 돌아오면 계속하기를 눌러 재개한다.
- 웨이브 진행 표시, 보드 상황별 안내, 스킬 남은 초와 사용 알림, 초기 이미지 로딩 화면, 결과의 강화 바로가기를 추가했다. 보상 저장이 끝나야 강화 화면으로 이동한다.
- 새 문구는 한국어·영어와 번역 CSV에 함께 반영했다. 좁거나 높이가 짧은 화면용 크기를 별도로 지정했다.

## 이미지 출처와 제작 방향

`assets/battlefield-v0924.webp`는 이번 작업에서 OpenAI 이미지 생성 도구로 새로 제작한 배경이다. 생성 원본에서 WebP로 포맷 변환했다. 기존 전장 파일은 과거 버전과의 구분을 위해 보존하고 런타임 참조만 새 파일로 연결했다.

제작 방향: 세로형 2D 판타지 디펜스용 탑다운 대장간 안뜰. 어두운 석재 중앙 공간, 화면 가장자리의 좁은 용암 수로와 청록 룬. 캐릭터·UI·글자·핵 오브젝트는 배경에 그리지 않고 게임이 별도로 표시한다. 적과 투사체가 지나가는 중앙의 대비를 낮추고 기존 수호자 그림과 어울리는 손으로 그린 질감을 사용한다.

스킬 아이콘과 UI 장식은 코드에서 그리는 SVG다. 새 배경음악·효과음은 오실레이터와 노이즈 기반의 절차적 합성이며 외부 음원이나 새 라이브러리에 의존하지 않는다.

## 실행 상태

저장소 `CLAUDE.md` 3항에 따라 자동 테스트, 게임 실행·플레이 검증, 디버깅 훅, 검증을 포함하는 `tools/build.mjs` 실행은 하지 않았다. 배포 ZIP도 만들지 않았다. 따라서 실제 렌더링, 브라우저별 오디오, 첫 플레이 진행, 중첩 일시정지·재개, 보상 저장 후 이동은 실기기에서 아직 확인되지 않았다.

`balance-editor.html`, 저장 스키마, 기존 전투 피해량·적 능력치·성장 가격·보상은 변경하지 않았다. 첫 플레이 안내를 위한 생성과 시간 제어만 추가했다. SDK 교체나 CrazyGames 재제출은 이 변경에 포함하지 않는다.


## v0925_1 · 모바일 화면 오류 수정

사용자가 제공한 두 화면에서 로비의 마일스톤·도감 버튼이 배너를 덮고, 전투 주문서에 이름이 표시되지 않는 문제를 확인했다.

- 로비 버튼 컨테이너에 남은 `top:14px`, 최대 폭, 오른쪽 정렬을 해제하고 하단의 높이 50px짜리 두 칸으로 고정했다. 기존 ID 선택자가 우선하던 999px 테두리 반경과 버튼 크기도 해당 컴포넌트 범위에서 교체했다. 목표 이름과 진행을 두 줄로 나누고 짧은 화면의 배너 여유를 확보했다.
- 주문서의 기존 `display:block`, 높이 17px, 오른쪽 여백을 교체했다. 제목은 아이콘과 두 줄 이름으로 표시하고 강화 레벨은 소환/강화 동작 옆으로 옮겼다. 준비 여부에 따라 예전 패딩 규칙이 다시 적용되지 않도록 선택자 범위를 맞췄다.
- 행동력 타이머를 재화 칸 안에 배치하고, 스킬 아이콘의 겹친 테두리와 보석의 예전 절대배치를 정리했다. 기본 버튼에도 새 테마가 같은 우선순위로 적용되도록 맞췄다.
- 변경한 CSS와 주문서 스크립트 참조에 버전 쿼리를 넣었다. 전투·성장·보상 계산과 이미지 자산은 변경하지 않았다.

확인은 `node --check js/board.js` 한 번으로 제한했고 통과했다. 모바일 로비·주문서 화면 확인은 브라우저 실행 파일이 없어 시작하지 못했다. 추가 설치나 광범위한 테스트, 플레이 검증, 배포 빌드는 수행하지 않았다.
