# 언어 추가 방법

개발자 없이 언어를 늘릴 수 있다. 필요한 건 `node`뿐이다.

## 1. 새 언어 만들기

```
node tools/i18n.mjs new ja 日本語
```

`i18n/ja.js`가 생기고 `index.html`·`dev.html`에 자동으로 등록된다. 값은 전부 비어 있다.

## 2. CSV로 빼서 번역하기

```
node tools/i18n.mjs export ja
```

`i18n/csv/ja.csv`가 생긴다. 칸은 `key · ko · ja` 세 개다.
**`ja` 칸만 채운다.** 엑셀·구글 시트에서 열면 된다(UTF-8 BOM이 붙어 있어 한글이 깨지지 않는다).

규칙 두 가지:

- `{n}` `{name}` 같은 **중괄호는 그대로 둔다.** 숫자·이름이 들어갈 자리다. 위치는 옮겨도 되고 개수만 맞으면 된다.
- `<b>` `<small>` 같은 **태그도 그대로 둔다.**
- 줄바꿈은 `\n` 두 글자로 적는다.

## 3. 다시 읽어들이기

```
node tools/i18n.mjs import ja
```

CSV의 내용이 `i18n/ja.js`에 들어간다. 빈 칸은 한국어로 대신 나오므로 **반쯤 번역한 상태로도 게임이 돌아간다.**

## 4. 확인

```
node tools/i18n.mjs check
```

번역 안 된 키, 중괄호 개수가 안 맞는 줄, 태그가 빠진 줄을 짚어 준다.
게임을 열어 ⚙ → 🌐 에서 언어를 고르면 바로 보인다.

## 나머지 명령

| 명령 | 하는 일 |
|---|---|
| `node tools/i18n.mjs list` | 언어별 번역 진행률 |
| `node tools/i18n.mjs sync` | 한국어에 키가 늘거나 줄었을 때 모든 언어 파일을 맞춘다 (기존 번역은 그대로) |
| `node tools/i18n.mjs sync ja` | 특정 언어만 |

**한국어 문구가 바뀌거나 새 화면이 생기면** `sync` → `export` → 새로 생긴 줄만 채우기 → `import` 순서로 따라가면 된다.

## 언어를 지우려면

`i18n/<코드>.js`를 지우고 `node tools/i18n.mjs sync`를 돌린다. `index.html`에서도 빠진다.

## 파일을 직접 고쳐도 된다

`i18n/ja.js`를 편집기로 열어 값만 바꿔도 똑같이 동작한다. 각 줄 위 주석이 한국어 원문이다.
CSV는 그 작업을 스프레드시트에서 하기 위한 통로일 뿐이다.

## 건드리지 말 것

- `index.html`의 `<!-- i18n:languages -->` 구간 — 도구가 관리한다.
- 따옴표 왼쪽의 **키 이름**.
- `i18n/ko.js` — 기준 언어다. 게임 문구 자체를 고칠 때만 손댄다.
